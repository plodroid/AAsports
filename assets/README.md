# AA Sport image slots

The site automatically checks this folder for these files:

- `hero.jpg` — main homepage image, portrait or 4:5 works best
- `coach-abdou.jpg` — Coach Abdou Attala
- `coach-self-defense.jpg` — self-defense coach
- `coach-hamid.jpg` — Hamid Saad

You can replace any image at any time without touching HTML, CSS, or JavaScript. JPEG, WebP-converted-to-the-same-filename, or optimized JPG files around 1200–1800 px on the long edge are ideal.

For additional gallery photos, create files here and add another `.image-slot` block in `index.html` using `data-image="filename.jpg"`.
